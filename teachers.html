გეოგრაფიის პედაგოგები და ექსპერტები

მონაცემები დინამიკურად იტვირთება JSONPlaceholder API-ს რესურსიდან (/users მეთოდი). პლატფორმაზე წარმოდგენილია საქართველოს გეოგრაფიის წამყვანი მასწავლებლები, მათი სპეციალიზაციები, საკონტაქტო ინფორმაცია და რეგიონები.

სტატუსი: 10 პედაგოგი
რესურსი: https://jsonplaceholder.typicode.com/users

🇬🇪 GeoEdu საქართველო

საქართველოს გეოგრაფიის სასწავლო პორტფოლიო. მე-6 გვერდი ეძღვნება გეოგრაფიის პედაგოგებს (JSONPlaceholder API).

სწრაფი ნავიგაცია

  • 1. გეოგრაფიული მდებარეობა
  • 2. რეკორდული მაჩვენებლები
  • 3. საქართველოს მდინარეები
  • 4. საქართველოს მღვიმეები
  • 5. ბუნება & პარკები (ახალი)
  • 6. პედაგოგები (API)

API ინტეგრაცია

გამოყენებულია https://jsonplaceholder.typicode.com/users REST API მეთოდი ასინქრონული fetch()-ით, შეცდომების მართვითა და საძიებო ფილტრაციით.
